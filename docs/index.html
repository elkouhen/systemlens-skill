Direct source analysis

Turn application evidence into an interactive architecture graph.

The skill reads a bounded application directly, creates a reviewable JSON fact manifest, imports it into SystemLens, and exports HTML without running systemlens index.

Follow the five steps

Five steps

01

Scope

Choose the application root, the architecture question, included services, and excluded directories.

02

Analyze directly

Read controllers, clients, listeners, publishers, persistence adapters, configuration, and local contracts.

03

Create facts

Write a systemlens-ai-graph-v1 manifest with stable IDs, relative evidence, status, and confidence.

04

Import

Initialize the repository and import the manifest into a dedicated namespace. This does not index source files.

05

Export

Generate the HTML graph and check that its topology matches the manifest and its evidence.

SystemLens handoff

Only three commands after analysis

The first command creates configuration. The second creates the empty compatible schema and imports facts. The third renders the imported graph.

systemlens init
systemlens import-facts architecture.ai-graph.json --namespace direct-analysis --complete
systemlens export microservices --html architecture.html

Validated path

Supermarket POC

The example analyzes order, inventory, and restock source files directly. The manifest records 16 topology facts and 3 ordered flows, imports them into an empty SQLite schema, and produces an HTML export. The source index remains empty.
