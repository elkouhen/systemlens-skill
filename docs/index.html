CodeQL-backed source analysis

Turn application evidence into an interactive architecture graph.

The skill installs and verifies CodeQL, creates a CodeQL-backed SystemLens source index, enriches it with direct source analysis, and exports a reviewable HTML architecture graph.

Follow the seven steps

Seven steps

01

Scope

Choose the application root, the architecture question, included services, and excluded directories.

02

Install CodeQL

Install the CodeQL CLI and verify it with codeql version.

03

Index

Create a CodeQL database, then index the application with the CodeQL-backed SystemLens engine.

04

Analyze directly

Read controllers, clients, listeners, publishers, persistence adapters, configuration, and local contracts.

05

Create facts

Write a systemlens-ai-graph-v1 manifest with stable IDs, relative evidence, status, and confidence.

06

Import

Import complementary facts into a dedicated namespace without duplicating indexed endpoints or flows.

07

Export

Generate the HTML graph and check that its topology matches the indexed model, manifest, and evidence.

SystemLens handoff

CodeQL baseline and enrichment

CodeQL creates the source database, SystemLens indexes it, then the manifest adds complementary facts and the export renders the result.

systemlens init
mkdir -p .codeql
codeql database create .codeql/systemlens-java --language=java --source-root=. --build-mode=none
systemlens index --full --call-graph-engine codeql --codeql-database .codeql/systemlens-java
systemlens import-facts architecture.ai-graph.json --namespace direct-analysis --complete
systemlens export microservices --html architecture.html

Supermarket POC
