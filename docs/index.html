Example enrichment

Explain the call graph.
Keep the evidence.

SystemLens finds potential flows. The skill adds one concise, source-grounded description per flow for the HTML export.

Open the complete prompt ↗ 
Run `systemlens flows list --json`.
Inspect every flow with `systemlens flows show`.

Write one sentence per flow that names:
the trigger, source component, and main effect.

Use ordered steps and source locations only.
Keep potential or unresolved flows qualified.
Write `.systemlens/flow-descriptions.json`.
Do not change indexed facts.

After review

Re-import facts.
Keep descriptions separate.

Topology manifests are imported into their own namespace. Flow descriptions stay in the presentation file used by the HTML export.

# topology facts
systemlens import-facts architecture.ai-<profile>.pass-001.json \
  --namespace ai-<profile>

# flow descriptions
systemlens export microservices --html architecture.html
